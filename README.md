# Cartógrafo del páramo

Editor de splatmap para el juego del páramo (Godot).

- **Web / PWA:** https://cimentacion.github.io/cartografo/
- **APK Android:** https://github.com/Cimentacion/cartografo/releases/latest/download/cartografo.apk

Los PNG y JSON que guardes desde la app van a `Descargas/Cartografo/`.
Cada cambio en `index.html` recompila el APK solo.
