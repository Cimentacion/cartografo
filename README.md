# El Páramo · Hasta el castillo

Juego cooperativo web para móvil (three.js + PeerJS). De noche todo el páramo parece el mismo brezo: quien guía tiene el mapa pero no ve a los caminantes (solo sus velas y lo que le cuentan); quien camina sabe dónde está pero no qué pisa. Hundimientos contados entre todos; con dos o más caminantes, compuertas en los ríos y un tablón que se levanta entre dos.

Jugar: https://raw.githack.com/Cimentacion/cartografo/paramo-coop/index.html
