# Witchstep: Castle of Night

(Antes "Cápsula Azul".) Metroidvania de casillas con vista cenital: una bruja azul contra siluetas rojas, del bosque al castillo.

- `index.html` — el juego completo (funciona sin internet). Jugar en el navegador:
  https://raw.githack.com/Cimentacion/cartografo/capsula-azul/capsula/index.html
- `mapa_castillo.json` — el mapa del editor del que sale este mundo.
- `../android-capsula/` — la app Android (WebView a pantalla completa). Cada push a la rama
  `capsula-azul` compila el APK y lo sube a la release **capsulaazul**.

La fuente Silkscreen es SIL OFL 1.1 (`OFL-Silkscreen.txt`, uso comercial permitido). three.js r128 es MIT.
